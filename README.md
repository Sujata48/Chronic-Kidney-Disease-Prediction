# Chronic Kidney Disease Prediction

## Overview
This project uses Machine Learning techniques to predict Chronic Kidney Disease (CKD) using the UCI CKD dataset.

## Objectives
- Data Cleaning
- Data Preprocessing
- Feature Selection
- Classification Models
- Performance Evaluation

## Algorithms Used
- Gaussian Naive Bayes
- K-Nearest Neighbours (KNN)
- Multi-Layer Perceptron (MLP)

## Tools
- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib

## Results
The models achieved high classification accuracy in detecting CKD patients.
